# Anadolu Hakimiyeti

Fetih, bilgi ve strateji: Anadolu'yu bilgi yarışmasıyla fethet.

## ⬇️ [Oyunu indir (Windows)](https://github.com/sayklord/anadolu-hakimiyeti-surumler/releases/latest/download/AnadoluHakimiyeti_Kurulum.exe)

### Kurulum
1. Yukarıdaki bağlantıdan **AnadoluHakimiyeti_Kurulum.exe** dosyasını indir ve çalıştır.
2. Windows "Windows kişisel bilgisayarınızı korudu" derse **Ek bilgi → Yine de çalıştır**'a bas.
3. Kurulum bitince masaüstündeki **Anadolu Hakimiyeti** simgesiyle aç.

### Güncellemeler
Oyunu her zaman masaüstündeki simgeden aç. Başlatıcı yeni sürümü kendiliğinden indirir; yalnız değişen dosyalar iner. Kayıtların güncellemede silinmez.

Sistem gereksinimi: Windows 10 veya 11, 64 bit.
